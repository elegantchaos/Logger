# Logger UI Improvements

Started `feature/logger-ui-improvements` from PR #37 head `d3990be` while its merge and release remain on hold. Added reusable channel controls for a list or menu, shared watcher injection, public channel actions and host-supplied bindings for command-driven applications. The master toggle uses SwiftUI's collection toggle for mixed state and disables itself when empty. Duplicate short names display their full identifiers with deterministic ordering.

The standalone SwiftUI example shares one watcher between its list and a macOS Debug → Channels menu and includes duplicate short names to exercise disambiguation. `agt validate --fast` passed. Sandboxed workspace validation could not open the workspace; the previously approved outside-sandbox workspace validation built the macOS example and passed all 16 package tests. In a disposable `agt vm` clone, verified Debug → Channels, both directions of list/menu synchronisation, the mixed master state, all-on and all-off, and disambiguated names through the accessibility tree. VoiceOver, keyboard navigation, other platforms and empty-state presentation remain unverified. Exact duplicate channel IDs still require an ownership decision; handler configuration remains separate follow-up work. After a button-action cleanup and removal of an unnecessary escaping annotation, the final workspace rerun built the example but its package-test phase stalled and was interrupted; separate final fast validation passed.
